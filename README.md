# SIGPROH

Sistema de Gestión Operativa para Propiedades Horizontales.

## Estructura inicial

- `apps/web`: aplicación Angular PWA.
- `apps/api`: API NestJS.
- `docs`: documentación del proyecto.
- `infrastructure/nginx`: configuración de Nginx.
- `.github/workflows`: automatización futura de CI/CD.

## Tecnologías principales

- Angular
- PrimeNG
- Tailwind CSS
- NestJS
- PostgreSQL
- Prisma
- Docker Compose
